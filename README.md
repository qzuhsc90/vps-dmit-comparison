## CN2 GIA 到底是什么，为什么 DMIT 要拿这个当卖点

先把这个概念说清楚，后面的选套餐逻辑才好理解。

CN2 GIA（China Telecom Next Carrier Network - Global Internet Access）是中国电信最顶级的国际专线，区别于普通的 163 骨干网，核心优势是晚高峰不降速、延迟稳定、丢包率极低。普通线路在晚上 8-11 点高峰期会严重拥堵，CN2 GIA 是独立优先通道，受拥塞影响小得多。

**DMIT 的整个产品体系，就是围绕这条线路能给到什么等级来分档的。**

DMIT 把自己的线路分成三档：

1. **Premium（Pro 系列）**：顶级档。三网 CN2 GIA 双向优化，电信联通去程走 GIA，移动去程走 CMI，三网回程全走 GIA。晚高峰表现最稳。
2. **Eyeball（EB 系列）**：中档。洛杉矶版本走 CMIN2 回程，香港版本走 CMI 三网，线路稍低一档，价格比 Pro 便宜，联通移动用户体验突出。
3. **Tier 1（T1 系列）**：纯国际线路，无中国大陆专项优化。适合面向海外用户的站点，或者需要大流量低成本的场景。

搞清楚这三档，再看套餐表就不会懵。
